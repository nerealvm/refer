# Угольный цикл — аналитика коммодити

Дашборд по большим циклам цен на уголь и ещё 19 коммодити. Цель — тайминг сделок и выбор коммодити.

## Что внутри

| Путь | Что это |
|---|---|
| `dashboard/coal-cycles.html` | Готовый дашборд, один файл, данные вшиты внутрь |
| `dashboard/template.html` | Шаблон страницы (вёрстка и графики) |
| `dashboard/research.html` | Раздел «Что смотрят профи» |
| `dashboard/method.html` | Раздел «Методология» |
| `pipeline/build.py` | Скачивает данные, считает циклы, собирает страницу |
| `data/events.json` | События для подписей на графике (ведём вручную) |
| `data/deals.json` | Сделки и банкротства в угле для графика (ведём вручную) |
| `data/*.csv` | Выгрузки: цены угля, фазы циклов, карта коммодити |

## Источники

- Всемирный банк, Pink Sheet: помесячные цены с 1960 года, уголь Newcastle с 1970, ЮАР с 1984.
- EIA: цена угля в США на шахте с 1949 года, экспортные цены энергетического и коксующегося угля с 2000.
- FRED: индекс потребительских цен США (CPIAUCNS) для пересчёта в реальные доллары.
- Д. Джекс (NBER w18874): реальный индекс цены угля 1850–2020, после 2020 продлён по Newcastle.

## Обновление

```bash
python -m venv .venv && .venv/bin/pip install pandas numpy openpyxl lxml
EIA_API_KEY=ваш_ключ .venv/bin/python -I commodities/pipeline/build.py
```

Без `EIA_API_KEY` используется демо-ключ EIA с жёстким лимитом запросов. Ключ бесплатный: https://www.eia.gov/opendata/register.php

С флагом `--offline` скрипт пересобирает страницу из уже скачанных файлов в `data/raw/`.

## Методика коротко

1. Цены переводятся в реальные доллары последнего месяца CPI.
2. Фаза цикла подтверждается, когда цена развернулась на +49% от дна или на −33% от пика. Фазы короче 6 месяцев склеиваются.
3. «Дорого/дёшево» — перцентиль текущей реальной цены к истории с 1970 года и к последним 20 годам.
4. Стадия («зрелый спад», «отскок со дна» и т.д.) — сравнение текущей фазы с медианой прошлых фаз того же товара.
5. Сигнал («окно покупки / продажи / наблюдать») — эвристика из стадии и перцентиля. Это не прогноз.

Подробно — во вкладке «Методология» дашборда.
