## Как печатать

1. Открыть `priglashenie-misha-bw-A4.pdf`.
2. Печать: A4, альбомная ориентация, масштаб 100 % («Фактический размер»).
3. Разрезать лист по пунктиру с ножницами — получатся две открытки.
4. Миша вписывает имя гостя в поле «Привет, …!».

Плотная бумага (160–200 г/м²) смотрится лучше, если принтер её берёт.

## Пересборка

```
npm install
node build.js
```

Нужен Chromium: путь задаётся переменной `CHROME`. Тексты, цвета и размеры — в `build.js`.

Шрифты Rubik и Pacifico распространяются по SIL Open Font License 1.1 (тексты лицензий — в `fonts/`).
Оформление вдохновлено стилем КидБурга; логотип КидБурга не используется.
